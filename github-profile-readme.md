## Профессиональный фокус

Основное направление — **Application Support L2 / Technical Support / Support Engineer**.

- Linux и сервисная диагностика: systemd, journalctl, Nginx, DNS, TLS и TCP/IP.
- Анализ HTTP/REST API, логов, request IDs и взаимодействия сервисов.
- SQL и PostgreSQL: проверка состояния данных, reconciliation и поиск расхождений.
- Python, pytest и Playwright: воспроизводимые проверки и автоматизация рутины.
- Документация расследований: timeline, RCA, runbooks и handover.

QA Engineering, API testing и Python automation — дополнительные компетенции, подтверждённые отдельными проектами.
