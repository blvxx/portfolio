# Модель данных и метаданные

Ниже приведена спецификация объектов, которые необходимо создать в Конфигураторе. Названия объектов и реквизитов должны совпадать с используемыми в BSL-файлах.

## Справочник Номенклатура

| Реквизит | Тип | Назначение |
|---|---|---|
| Артикул | Строка(30) | Уникальный или отображаемый код товара |
| ЕдиницаХранения | Строка(20) | Единица учета |
| Активен | Булево | Доступность для новых операций |

Стандартное поле Наименование используется для отображения товара.

## Справочник Склады

| Реквизит | Тип |
|---|---|
| Комментарий | Строка(250) |

Стандартное поле Наименование содержит название склада.

## Справочник Контрагенты

| Реквизит | Тип |
|---|---|
| ИНН | Строка(12) |
| Телефон | Строка(30) |
| ЭлектроннаяПочта | Строка(100) |

## Регистр накопления ТоварныеОстатки

Вид регистра: **Остатки**.

| Тип элемента | Имя | Тип |
|---|---|---|
| Измерение | Номенклатура | СправочникСсылка.Номенклатура |
| Измерение | Склад | СправочникСсылка.Склады |
| Ресурс | Количество | Число(15, 3), неотрицательное при корректном проведении |

## Документ ПоступлениеТоваров

Реквизиты: Склад, Поставщик, Комментарий.

Табличная часть Товары: Номенклатура, Количество, Цена, Сумма.

## Документ РеализацияТоваров

Реквизиты: Склад, Покупатель, Комментарий.

Табличная часть Товары: Номенклатура, Количество, Цена, Сумма.

## Документ ПеремещениеТоваров

Реквизиты: СкладОтправитель, СкладПолучатель, Комментарий.

Табличная часть Товары: Номенклатура, Количество.

## Соглашения об именовании

- Метаданные названы по-русски, согласно распространенной практике конфигураций 1С.
- Имена реквизитов и регистров должны полностью совпадать с текстом модулей.
- Количество хранится с точностью до трех знаков после запятой.
- Время и период движения задаются стандартным реквизитом Дата документа.
