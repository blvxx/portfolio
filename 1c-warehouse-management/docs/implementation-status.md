## Ограничения текущего состояния

1. Файлы BSL — исходные примеры для переноса в модули конфигурации, а не готовая выгрузка конфигурации.
2. Объекты метаданных еще нужно создать по data-model.md.
3. Код должен пройти синтаксическую проверку на целевой версии платформы 1С:Предприятие 8.3.
4. Для реальной многопользовательской эксплуатации нужна отдельная реализация конкурентно-безопасного контроля остатков.
5. До запуска тест-кейсов их результат считается неизвестным.

## План ближайшей работы

1. Создать пустую учебную конфигурацию с управляемым приложением.
2. Добавить справочники и регистр накопления ТоварныеОстатки.
3. Добавить документы поступления и реализации с указанными реквизитами и табличными частями.
4. Перенести BSL-код в соответствующие модули.
5. Выполнить проверку конфигурации и исправить ошибки.
6. Пройти тест-кейсы и приложить доказательства результатов.
