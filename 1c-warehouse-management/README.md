# 1C Warehouse Management

Учебный проект на платформе **1С:Предприятие 8.3**: складской учет, поступление и реализация товаров, контроль остатков и базовая аналитика.

> **Статус:** проект в разработке. Репозиторий содержит спецификацию, архитектуру и первые примеры модулей BSL. Для запуска требуется перенести объекты и код в конфигурацию 1С:Предприятия, создать метаданные по документации и выполнить проверку в Конфигураторе. Коммерческая эксплуатация не заявляется.

## Цель

Разработать демонстрационную конфигурацию для небольшой торговой компании, которая ведет учет номенклатуры на нескольких складах.

## Функциональность в плане

- ведение справочников номенклатуры, контрагентов и складов;
- оформление поступления и реализации товаров;
- перемещение товаров между складами;
- регистрация количественных остатков в регистре накопления;
- контроль заполнения документов и достаточности остатков;
- отчеты по остаткам и продажам;
- ручные тестовые сценарии и документация по бизнес-правилам.

## Технологии

- 1С:Предприятие 8.3;
- встроенный язык 1С (BSL);
- язык запросов 1С;
- справочники, документы, табличные части;
- регистры накопления;
- Git / GitHub.

## Бизнес-сценарий

1. Пользователь создает документ поступления, выбирает склад и добавляет товары с количеством.
2. При проведении документ формирует приходные движения регистра ТоварныеОстатки.
3. Пользователь создает реализацию, указывает склад и состав товаров.
4. Перед проведением система проверяет, достаточно ли товара с учетом всех строк документа.
5. При успешной проверке реализация формирует расходные движения.
6. Остатки могут быть получены запросом к виртуальной таблице регистра накопления.

## Важно

Код в папке src — исходные модули-примеры, предполагающие описанные в документации имена объектов метаданных. До сборки конфигурации необходимо создать соответствующие метаданные, свойства и реквизиты в Конфигураторе, затем выполнить синтаксическую проверку и тестирование на платформе 1С.
