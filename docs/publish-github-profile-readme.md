## Navigation structure

The profile has one employer-facing entry point:

- **Career portfolio:** https://blvxx.github.io/portfolio/

The portfolio links to supporting technical evidence repositories without presenting them as separate role-specific portfolios.

Commercial services and client-facing work are kept separate:

- **Web Development & SMM:** https://blvxx.github.io/Web-Development-Services/

## Updating the profile

1. Edit `README.md` in [blvxx/blvxx](https://github.com/blvxx/blvxx).
2. Keep the career portfolio as the primary link.
3. Keep supporting engineering repositories under a short evidence section.
4. Keep services and independent products in a separate section.
5. Check the rendered profile at https://github.com/blvxx after saving.

The source copy of the current profile text is stored in [github-profile-readme.md](../github-profile-readme.md) in this repository.
