# Publish the GitHub profile README

GitHub displays a profile README when a **public repository with the exact same name as the username** exists and contains a root-level **README.md**.

For this account:

1. Open https://github.com/new
2. Create a **Public** repository named exactly **blvxx**.
3. Add a README file, or leave the repository empty and upload this file afterward.
4. Copy the contents of **github-profile-readme.md** from the root of this repository into the new repository's **README.md**.
5. Save the commit and open https://github.com/blvxx to check the profile.

Do not create **blvxx-profile**, **profile**, or another variation: GitHub requires the repository name to match the username exactly.

The profile README links to the engineering showcase at **https://blvxx.github.io/portfolio/engineering/** and the separate website-development portfolio at **https://blvxx.github.io/portfolio/**.
