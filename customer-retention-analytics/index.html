01 / Project scope

Business questions,
not just charts.

The focus is on turning a transaction table into a set of understandable metrics and customer-level views, with explicit definitions and limitations.

01 / SALES

Sales performance

Gross sales, refunds, net sales, monthly trends, country contribution and top products.

02 / CUSTOMERS

Repeat purchasing

Identified customers, invoice frequency and the observed repeat-customer rate.

03 / SEGMENTATION

RFM groups

Recency, frequency and monetary scores using relative quartiles within the observation window.

04 / RETENTION

Cohort analysis

Monthly customer cohorts and the share returning in later observed months.

05 / QUALITY

Data validation

Invalid dates, quantities and prices, cancellations, returns and missing customer IDs.

06 / DELIVERY

Reproducible outputs

Python pipeline, unit tests, CSV/JSON exports and a Streamlit + Plotly dashboard.

02 / Data provenance

Open data, clear
attribution.

The project uses the original published UCI workbook. The raw file is downloaded on demand rather than copied into this repository.

UCI Online Retail

A historical transaction dataset for a UK-based non-store retailer. The source describes 541,909 transaction rows over the period 1 December 2010 to 9 December 2011. Unit prices are denominated in sterling.

  • 541,909 published transaction rows
  • Historical period: Dec 2010 – Dec 2011
  • Source license: CC BY 4.0

Data handling rules

Sales and customer metrics use explicit treatment rules so the result can be interpreted and reproduced.

  • Negative-quantity lines and cancellation invoices are separated as refunds/cancellations.
  • Sales without CustomerID remain in revenue KPIs but not customer-level calculations.
  • RFM scores are relative segments, not churn probabilities.
  • Historical observations do not establish marketing causality or current market trends.
Transparency: the included CSV preview is a small synthetic test fixture, not a subset of UCI records. The source workbook is not bundled. No numerical findings are presented on this page until the original dataset is downloaded and processed.

04 / Reproducibility

Run it locally.

Python 3.10+ is required. The Streamlit dashboard can use a small synthetic preview fixture or the original workbook uploaded locally.

Download and run the analysis

python -m venv .venv
pip install -e ".[dev]"
python scripts/download_data.py
python scripts/run_analysis.py
pytest

The pipeline writes CSV tables, a JSON KPI summary and a generated findings report into outputs/.

Launch the dashboard

pip install -e ".[dashboard,dev]"
streamlit run app.py

Upload the official UCI workbook in the sidebar to switch from the synthetic preview to the source dataset.
