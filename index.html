03 / Процесс

Понятно на каждом этапе

Без неопределённости в объёме работ: сначала разбираемся с задачей, затем согласуем результат.

01

Разбираю задачу

Изучаю текущий сайт или идею, уточняю аудиторию, цель и необходимые функции.

02

Фиксируем план

Согласуем структуру, состав работ, сроки и стоимость до начала разработки.

03

Разрабатываю

Собираю страницы, добавляю нужные сценарии и проверяю адаптивность.

04

Передаю результат

Проверяю основные сценарии, публикую сайт или передаю готовые изменения.

Внимание
к тому, что

Я Артём Калинин. Работаю на стыке веб-разработки, тестирования и технической поддержки.

В проектах использую HTML, CSS и JavaScript для интерфейсов, Python и pytest для автоматизации проверок, SQL и PostgreSQL для работы с данными. Знаком с REST API, Postman, Playwright, Docker, Linux и GitHub Actions.
